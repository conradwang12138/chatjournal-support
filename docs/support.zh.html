找回记录与草稿

从首页的“浏览记录”、搜索或日期入口查找记录。误删的记录可在“最近删除”中选择“恢复”。已经“永久删除”的记录不能从该页面恢复。

要查找草稿或以前的内容，打开“设置 → 备份与导入 → 草稿与历史版本”。普通记录的菜单也有“历史版本”。恢复历史正文与附件会保留当前内容为另一个历史版本；不会替你解决未处理的分类。

使用自动整理

自动整理默认关闭。在“设置”中开启时，App 会先检查当前可用内存。首次使用需要你确认从 Hugging Face 及其分发网络下载 2.74 GB（2,740,937,888 字节）模型，并完成校验；需要联网和足够空间。下载服务可获得 IP 地址等连接信息，不包含记录正文或附件。不需要模型账号或密钥。原文和附件先保存，模型随后在设备上整理已保存的可见正文，也可能整理已有记录；正文和附件不会上传给开发者或模型提供方。

下载中可以取消。取消后，重新打开“自动整理”可再次确认下载；下载失败且出现“重试”时，可点“重试”。能够安全续传时继续，否则重新下载。取消或失败不会自动开启整理。在设置中选择“移除模型”会停止整理并移除模型文件，保留原文和附件。需要时可重新下载。可用内存不足或暂时无法确认时，仍可继续记录，稍后重试。

自动整理可以补充分类和已有标签、从明确未完成的行动中提取待办。它不会为每条旧记录都补待办：早期记录默认只整理分类，新记录可根据行动标为待办。需要时请直接手动修改分类、标签或待办。它只处理文字，不直接识别照片或音频；你主动加入正文的识字或转写文字也可被整理。它不会回复记录或自动设置通知。

出现“整理未完成，记录已保存。可重试。”“内存不足，整理已暂停。记录已保存。”或内容过长提示时，已保存的记录和附件仍在。你可以继续记录，稍后再点“重试”；不要反复导入或重建记录来触发整理。关闭“自动整理”会停止新的整理，保留已保存结果。

记录和附件、记录备份和原始文件备份可以保留相应的整理信息，包括行动原文片段；单独的可读 Markdown 或纯文本不包含完整整理元数据。你独立开启 iCloud 同步后，这些信息也可随记录同步。详情见 隐私政策。

Pro 月订阅、年订阅和买断提供相同的自动整理权益，不设商业条数上限。购买前须已下载模型，且当前设备有条件运行。内存和设备保护仍有效，购买不保证每次整理都成功。设置中的“购买与恢复”显示 Apple 返回的当前价格、计费周期和试用资格。符合 Apple 资格时，月或年订阅可享14天免费试用，之后按所选商品显示的价格与周期自动续订。可在“管理订阅”中取消续订。

换机或重新安装后，可以主动选择“恢复购买”。恢复和管理已有购买不要求先下载模型。买断不会替你取消已有订阅，如不再需要订阅，请另行取消。购买适用 Apple标准使用条款。

备份、导出与导入

打开“设置 → 备份与导入”。需要恢复用的完整副本时，选择“备份所有记录”；它包含隐藏内容、最近删除内容、历史、原附件、草稿和界面设置。需要可携带的所选记录时，使用“导出记录”，并根据需要选择“记录和附件”、Markdown 或纯文本。

通过“导入记录或备份”选择文件，先查看导入内容，再确认。不要只保存附件包内部的一部分文件。原始文件备份用于保留底层存储文件；恢复它会先建立独立副本，不直接覆盖当前资料库。

备份及导出不额外加密。请保留独立副本，并在分享前检查是否包含隐藏、最近删除或历史内容。详情见 隐私政策。

相机、录音、识字或转文字不可用

在系统设置中检查相机、麦克风和语音识别权限。语音识别权限被拒绝时，可点 App 中的“打开设置”前往系统设置。拒绝可选权限后，普通文字记录及可用的文件导入仍可使用。

识字在设备上运行。音频转文字依赖设备、系统和语言的本地 Speech 支持；不支持时不会改用云端转写。你仍可保留或导出原音频。长文件可能需要等待，请避免重复点按导入。

同步与网络

“设置 → iCloud → 同步记录”默认关闭。开启前请确认设备已登录你的 Apple 账号，iCloud 有足够空间且网络可用。同步等待或失败时，已保存的本机记录仍保留；请查看状态，再使用“立即同步”。账号变更后需要重新开启同步。

关闭同步不会清除既有云端副本。不要用删除 App 或反复导入备份来排查同步，以免增加副本；先保存独立备份并联系支持。真实服务和其他设备的可用性由系统及网络条件决定。

“联网预览”默认关闭。它只控制 App 获取网页预览；你主动打开网页、从云端照片或文件提供方导入内容仍可能联网。

隐藏和永久删除

隐藏不是加密。“永久删除”关闭 App 内的恢复路径，不保证安全擦除历史文件、原附件、备份或云副本。删除记录前如需保留，请先备份；需要清除所有副本时，也要检查你另存和已分享的位置。
